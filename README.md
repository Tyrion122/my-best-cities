# Мої 3 найкращі міста світу

Навчальний статичний багатосторінковий web-сайт (блог), розроблений у межах **Лабораторної роботи №1** з дисципліни «WEB-програмування».

## Мета проєкту
Опанування семантичної HTML-розмітки, організації структури багатосторінкового web-проєкту, створення навігації за допомогою відносних посилань, роботи з HTML-формами, а також версіювання за допомогою Git і публікації через GitHub Pages.

## Структура проєкту
- `index.html` — головна сторінка блогу з коротким описом та навігацією;
- `city-kyiv.html` — сторінка про місто Київ;
- `city-kyoto.html` — сторінка про місто Кіото;
- `city-barcelona.html` — сторінка про місто Барселона;
- `form.html` — сторінка з HTML-формою для пропозиції нового міста;
- `images/` — каталог із графічними ресурсами сайту.

## Використані технології
- HTML5 (семантична розмітка, форми, таблиці/списки, мультимедіа)
- Git & GitHub
